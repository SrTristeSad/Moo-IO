# Arte incluída no Moo-IO (CC0)

**Este pacote NÃO contém as imagens do MooMoo.io/FRVR.**

As 180 imagens distribuídas em assets/custom/img foram derivadas das artes
**Kenney** (Creative Commons Zero 1.0 Universal), com redimensionamento e
algumas variações de cor. Elas são alternativas temporárias visualmente
diferentes dos sprites do MooMoo.io; alguns equipamentos e animais não possuem
um equivalente visual exato. Nomes e caminhos seguem o protocolo do jogo
para evitar arquivos ausentes.

Origem CC0: https://kenney.nl/assets/generic-items
e https://kenney.nl/assets/animal-pack-remastered
e https://kenney.nl/assets/fish-pack

Snapshot (repositório que espelha os pacotes Kenney CC0):
https://github.com/shorepine/kenney/tree/3694c6879e487c108f55677be7dd2ca75b07cc3b

Licença: https://creativecommons.org/publicdomain/zero/1.0/

A geração das imagens ocorreu no GitHub Actions, uma única vez, para que
todos os PNGs fiquem versionados. O jogador **não** precisa baixar imagens
nem converter formatos na inicialização.

A arte autoral do usuário pode substituir qualquer arquivo correspondente
sem depender de conversão ou download.

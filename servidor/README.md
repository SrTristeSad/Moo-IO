# Moo-IO — Servidor privado V2

A primeira implementacao de personalizacao de salas e mods esta em [v2/](v2/README.md).

V2 reutiliza o motor de jogo Node.js existente, nao modifica os clientes e possui salas independentes com regras personalizadas por arquivos JSON. Modificacoes de novos assets, scripts e infraestrutura de VPS publica requerem as proximas etapas.

O servidor para LAN embutido nos clientes nao foi substituido.

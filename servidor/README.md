# Moo-IO — servidores

## V2 dedicado (em desenvolvimento)

O servidor de partida independente esta em [v2/](v2/README.md). Ele reutiliza o motor autoritativo Node.js existente, permite criar uma instancia privada por linha de comando, configura IP/porta/convite/bots e pode ser empacotado sem os clientes Windows/Android.

**Os clientes atuais continuam intactos.** O Node.js que hospeda salas do Windows permanece em [../windows/server/](../windows/server/); o Android continua incluindo seu proprio servidor integrado.

A V2 ainda e limitada a LAN/VPN confiavel. Nao use como servidor publico na internet.
